# Decimal to Binary in Java

A simple Java program to convert a decimal number into its binary equivalent.

## Description

This program takes a decimal number as input and converts it into binary using division and remainder operations.

## Example

For decimal number `10`:

`10 ÷ 2 → 1010`

Therefore:

`Decimal = 10`
`Binary = 1010`

## Sample Output

```text
Enter a decimal number: 10
Binary = 1010
```

* Java
* Scanner
* while loop
* Division and remainder
* Number conversion
